# Glossary

## Thuật ngữ AI

| Thuật ngữ            | Diễn giải trong phạm vi dự án                                                                                      |
| -------------------- | ------------------------------------------------------------------------------------------------------------------ |
| AI                   | Trí tuệ nhân tạo (Artificial Intelligence).                                                                        |
| AI Agent             | Thành phần hỗ trợ người dùng tìm kiếm, tư vấn, đánh giá và so sánh sản phẩm thông qua tương tác ngôn ngữ tự nhiên. |
| LLM                  | Large Language Model — mô hình ngôn ngữ lớn dùng để hiểu và tạo phản hồi cho truy vấn người dùng.                  |
| NLP                  | Natural Language Processing — xử lý ngôn ngữ tự nhiên.                                                             |
| Semantic Search      | Tìm kiếm dựa trên ý nghĩa/ngữ cảnh của truy vấn thay vì chỉ so khớp từ khóa.                                       |
| Embedding            | Biểu diễn dữ liệu văn bản/truy vấn dưới dạng vector để phục vụ tìm kiếm ngữ nghĩa.                                 |
| RAG                  | Retrieval-Augmented Generation — truy xuất dữ liệu liên quan trước khi đưa ngữ cảnh vào LLM để sinh câu trả lời.   |
| Vector Database      | Kho lưu trữ vector phục vụ truy vấn tương đồng; report sử dụng Qdrant.                                             |
| Orchestrator-Workers | Mẫu Agent trong đó một bộ điều phối phân chia yêu cầu cho các thành phần/worker xử lý rồi tổng hợp kết quả.        |
| Fine-tuning          | Tinh chỉnh mô hình đã được huấn luyện trước trên dữ liệu mục tiêu.                                                 |
| Precision            | Trong report, tỷ lệ các phát biểu chatbot đưa ra được xác định là đúng so với dữ liệu tham chiếu.                  |
| Recall               | Trong report, mức độ câu trả lời bao phủ các thông tin cần có trong dữ liệu tham chiếu.                            |

## Thuật ngữ thương mại điện tử

| Thuật ngữ                           | Diễn giải                                                                                                                  |
| ----------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Khách hàng                          | Người dùng cuối xem/tìm sản phẩm, thao tác giỏ hàng, đặt hàng, thanh toán, xem lịch sử, đánh giá sản phẩm và dùng chatbot. |
| Nhân viên (Employee)                | Quản lý sản phẩm, biến thể, danh mục, thương hiệu, khách hàng, khuyến mãi, đơn hàng, hóa đơn và thanh toán. |
| Quản trị viên (Admin)               | Quản lý tài khoản nhân viên, xem tổng quan và thống kê; không bao gồm quyền của nhân viên. |
| Sản phẩm (Product)                  | Mặt hàng điện tử được kinh doanh trên hệ thống.                                                                            |
| Biến thể sản phẩm (Product Variant) | Phiên bản cụ thể của một sản phẩm, có thể khác nhau theo màu sắc, RAM, bộ nhớ, kết nối, SKU, giá và số lượng.              |
| Danh mục (Category)                 | Nhóm phân loại sản phẩm.                                                                                                   |
| Nhãn hiệu (Brand)                   | Thương hiệu của sản phẩm.                                                                                                  |
| Giỏ hàng (Cart)                     | Danh sách sản phẩm người dùng chuẩn bị mua, cho phép thêm, sửa số lượng và xóa.                                            |
| Đơn hàng (Order)                    | Giao dịch đặt mua được tạo từ giỏ hàng cùng thông tin giao hàng, thanh toán và khuyến mãi nếu có.                          |
| Mã giảm giá / Khuyến mãi            | Cơ chế giảm giá theo dòng hàng hoặc theo đơn (voucher có mã hoặc tự động), do cửa hàng quản lý và có điều kiện áp dụng.                                                         |
| Thanh toán (Payment)                | Giao dịch thanh toán của đơn hàng, bằng COD hoặc VNPAY (online).                                                         |
| Đánh giá sản phẩm (Review)          | Đánh giá của khách hàng sau khi mua sản phẩm.                                                                              |
| OTP                                 | Mã 6 số gửi qua email (hiệu lực 5 phút), dùng khi đăng ký, quên mật khẩu và đổi mật khẩu.              |

## Thuật ngữ trải nghiệm

| Thuật ngữ                 | Diễn giải                                                                                           |
| ------------------------- | --------------------------------------------------------------------------------------------------- |
| Truy vấn tự nhiên         | Câu hỏi, mô tả hoặc từ khóa tiếng Việt không yêu cầu cú pháp cố định.                               |
| Tư vấn sản phẩm           | AI hỗ trợ người dùng tìm hiểu sản phẩm và đưa ra gợi ý theo nhu cầu.                                |
| So sánh sản phẩm          | AI hỗ trợ đối chiếu thông tin sản phẩm để người dùng dễ đưa ra quyết định.                          |
| Đánh giá sản phẩm bằng AI | Phân tích/nhận xét sản phẩm dựa trên dữ liệu sản phẩm và dữ liệu liên quan được hệ thống truy xuất. |
